Working prototypes

Purchase Approvals for Pros, in your hands

Three clickable prototypes rebuilt from the final comps, one per phase and role: the account owner sets up a workflow, a requester submits an order, an approver decides. Each one keeps its own state, so you can change quantities, add comments and see every status change. The original 2022 walkthrough video sits behind a tab.

Phase 1 · Account owner

Set up a workflow

Joel names a workflow, picks requesters, sets a $500 spend limit and picks approvers in four steps. Creating it notifies everyone by email and text, and the list is where he edits, disables or deletes it later.

Phase 2 · Requester

Submit a request

Mark shops as usual. The cart warns him the order is over the limit, checkout swaps Place Order for Submit for Review, and My Requests tracks the request. Drop the cart under $500 and it places like any other order.

Phase 3 · Approver

Approve a request

Kim hears about the request by email, text and a homepage alert. She can approve or reject from the dashboard in two clicks, or open the request to change quantities, leave comments and decide with the full order in view.
