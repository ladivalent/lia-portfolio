Context starter row

A prompt that carries what it points at. Use it whenever the question only makes sense with an item, a photo, a cart or a vehicle attached. In the future state it lives in History, under Pick up where you left off.

Where things live

History, Alerts and Memory each have one job.

HistoryHolds the task.
  • Pick up where you left off: suggestions that carry their item
  • Running: watches and hunts, each with its status
  • Past chats by date, with how each one ended

How to get there. The clock in the side rail, or the pick up where you left off link on the start screen. iOS: the clock in the header.

AlertsHolds the moment it needs you.
  • Needs you: one action per alert, like Review bid or Check out
  • Updates: seller messages, shipping, listings the agent set aside
  • The bell count is how many need you

How to get there. The bell in the side rail. iOS: the bell in the header.

MemoryHolds what AI Mode knows.
  • Sizes, car, limits, places, people and preferences, each with its source
  • A switch for each signal: viewed items, cart, photos, watches
  • Use memory on or off, and Delete all memory

How to get there. Manage under the composer, or the avatar, then Memory and preferences. iOS: History, then your name.

One task can show in two places. The Canon AE‑1 watch sits in History the whole time and shows in Alerts only when it needs your OK to bid.

Rules

  • No context, no row. A prompt that says this, my cart or my car only appears when that thing is real and shown. With no history, the section hides. It never falls back to the bare question.
  • The context travels. Picking the row attaches the item to the composer as a chip, fills the question and switches the mode.
  • Only the shopper's own context. Viewed items, the cart, a saved vehicle, uploaded photos. Never an item the shopper didn't touch. Only they see it, and Manage shows where each one came from.
  • Same row family. In a list, the same divider, arrow and hit area as the plain prompt row. In a side panel, the same rounded hover as every panel row. The thumbnail is the only signal that a row carries context.
  • Self-contained prompts stay plain. Find Levi's 501s that fit like my Madewell 29s needs no attachment, so it uses the plain row.
