# Lia DiValentin — Portfolio

Static portfolio site (Home, Process, Work, Résumé, Contact). No build step: every page is plain HTML rendered in the browser by `support.js`.

- Entry: `index.html` (same as `Home.dc.html`)
- Résumé PDFs: `resume/`
- Embedded case studies and prototypes: `embeds/`

Hosted on Vercel — every push to `main` redeploys.
