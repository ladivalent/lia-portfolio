The pipeline — six layers, six owners
L1 Signal extraction — what the user said
L2 Context enrichment — what we know about them & the world
L3 Intent & routing — calibrated confidence × stakes
L4 Response policy — the decision spine picks the move
L5 Execution — search, facets, disambiguation UI
L6 Feedback — overrides & accepts re-tune Ask ↔ Act
The rule that never bends
If it can't be undone — a trip, a payment, a bid, a meetup — the agent asks first. Every time. At any confidence.
Stakes override signal strength — a confident detection still asks before it costs someone a Saturday.
Trust ledger — how LEARN moves the dial
EARN Say yes a few times → it stops asking about that one thing.
LOSE Fix it three times → it goes back to asking.
NOTE Quiet is never secret — every choice leaves an undoable receipt.
“another barstool like last time” → 0.74 → Act, visibly.
The discipline of doing nothing
“USB-C cable 2m braided” → 0.08 → stays out of the way
“Nike AF1 Low size 10.5” → 0.96 → just shows
A terse expert query is an instruction, not an invitation. A no-op is a scored decision, not an absence.
