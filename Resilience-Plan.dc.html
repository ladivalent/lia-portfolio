The fallback plan when agents fail

Three operating modes for when model quality lags or systems go down, the manual fallback for every phase, and where the work is stored and backed up. The process degrades gracefully — it never stops.

A · Phase matrix B · Orchestrated pipeline C · Stage-gate blend Evolution 2022→26 Resilience plan
MODE 0 · NORMAL
ACTIVE
Full orchestration
Agents draft, loops run between rituals, humans approve at the gates.
All subagents and automation loops on
Agent output spot‑checked at gates
Health check: weekly eval dashboard review
MODE 1 · DEGRADED
ACTIVE
Draft‑only agents
Declared when model quality lags, latency spikes, or evals dip below the bar.
Auto‑actions and loops paused; agents draft only
Humans re‑take synthesis, QA, and audits
Every agent draft gets a second reviewer
Target: restore or roll back same‑day
MODE 2 · OUTAGE
ACTIVE
Manual craft
Full outage or trust incident: run the 2022 process — it still works.
Workshops, manual synthesis, hand‑made specs
SLAs stretch; the quality bar does not
Nothing about shipping depends on an agent
Rule: gates 1–4 run unchanged — they were always human

Where the work lives — storage & backup
Design source
System of record: Figma cloud, org‑managed, 30‑day version history + branching.
Backup: nightly .fig snapshots to the design‑vault repo on GitHub.
Research & insights
System of record: Dovetail; consent forms in an access‑controlled vault, transcripts PII‑redacted.
Backup: weekly export to Confluence + company drive; study tracker in Airtable.
Decisions & specs
System of record: Confluence + Google Docs (briefs, gate decisions, specs), human‑readable without any agent.
Backup: quarterly HTML/PDF archive to cold storage.
Tokens, code & prototypes
System of record: Git repos — tokens are canonical; Figma variables sync from the repo.
Backup: mirrored remotes; Storybook rebuilt from source.
Agent memory & context
Disposable cache: vector index + prompt configs in company cloud storage.
Recovery: rebuilt on demand from the systems of record above — nothing lives only here.
The rule that makes this work: agents hold caches, never the source of truth. Every system of record is human‑readable SaaS with scheduled exports — losing the agents loses speed, not work.
BACKUP CADENCE Continuous Git + Figma history Nightly .fig snapshots + agent reindex Weekly research exports Quarterly full archive + restore drill The drill is the point: a backup you never restored is a hope, not a plan.
When it breaks, in order
Design ops declares the mode in #ux‑ops and on the status page. Phase owners switch to their manual rituals. Work ships anyway. Retro within 48 hours; agents return only after evals pass.
