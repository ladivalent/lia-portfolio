The UX process, phase by phase

My playbook is a working document, not a poster. It shows five phases of a corporate UX engagement — the workflow, the human toolstack, and the AI agent team assisting at each step — plus how the same pipeline runs as an orchestrated agent team, how stage gates blend with an always-on agent rail, how the process evolved from 2022 to 2026, and what happens when the agents fail.

Principles

How they’re built
One job eachEvery skill owns one part of the playbook, with a defined output and a check before anything is shown.
Load only what’s neededCore steps live in SKILL.md. Longer references load only when a step calls for them, which keeps token use down.
Learns and stays currentStandards grow from my confirmed edits, and a refresh checks every skill against the newest model.
